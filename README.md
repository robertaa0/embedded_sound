Įterptinės sistema, matuojanti garsą, sukurta naudojant STM32F091RC mikrovaldiklio kūrimo plokštę. 
Įrenginys realiuoju laiku matuoja garso signalo vidutinę kvadratinę įtampą bei dažnį, naudoja skaitmeninį filtravimą ir leidžia konfigūruoti parametrus per UART sąsają.
Rezultatai atvaizduojami LCD indikatoriuje (16x2) bei perduodami į kompiuterį per UART sąsają.
